Multi-volume RAR 5 sets built by the `rars` crate (64 KB volumes) and checked against the
official UnRAR when generated; `src/` holds the original files.
- `vol.partN.rar`: new-style names, not solid
- `vol-solid.rar`, `.r00`, `.r01`: old-style names, solid
- `vol-enc.partN.rar`: solid, encrypted names and data, password `parça şifresi`
